### Этап 2. Работа с данными (Данные.csv)
Проверили файл и привели данные к единому виду:
- Обхват головы: везде длинное тире без пробелов (`59–60`, `61–62`).
- Тип шлема: `Интеграл` с заглавной буквы у AVT-FF-XL.
- Гарантия: у AVT-MD-L `24 месяца` заменено на `2 года`.
- Визор: у кроссовых шлемов вместо пустой ячейки стоит `Нет`.
- Вентиляция разбита на две числовые колонки: «Вентиляция, входов» и «Вентиляция, выходов».
- Добавлена колонка «Козырёк» (`Есть` у Кросса и Адвенчера, у остальных `Нет`).
- В выгоде Модуляра добавлена запятая: «говорить, не снимая».

Сознательно оставлено как есть: Pinlock внутри поля «Визор», разный набор размеров у моделей, повторяющиеся значения в строках, формат файла.

### Этап 3. Excel
- Создан [Данные.xlsx](Данные.xlsx) с листом «Данные».
- Пустой вес AVT-OF-L закрашен красным, в ячейке комментарий «Нет данных». Вес искали в интернете, ничего не нашли.
- Добавлен лист «Худший случай»: одна строка, где в каждом поле стоит самое длинное значение по числу символов. Нужен, чтобы проверять, помещаются ли тексты в макет.
- Значения этого листа посчитаны скриптом, а не формулами (в рабочей среде не было пересчёта формул). После изменения данных лист нужно пересобрать.
