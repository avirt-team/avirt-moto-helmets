# АВИРТ — мастер-макет карточек мотошлемов

Мастер-макет для маркетплейса: 4 кадра 1080 × 1440 на артикул. Новый артикул собирается подстановкой
данных в свойства компонента, без захода внутрь слоёв. Макет готов к автоматической подстановке
(следующий модуль).

**Figma:** https://www.figma.com/design/Bj2WZgwceZVhKFuZ4x4Bkq

## Что где лежит

| Путь | Что это |
|---|---|
| `Данные.csv` | 10 артикулов, приведённые в порядок. UTF-8 с BOM, `;`, 20 полей. Источник правды |
| `Данные.md` | та же таблица для чтения глазами, собирается из `.csv` |
| `Журнал правок данных.md` | что исправлено в выгрузке и как; что на контроле у заказчика |
| `Критерии кадра.md` | проверяемые правила готового кадра (для проверяющего агента) |
| `Экспорт/` | PNG карточек: `<Артикул>_<1–4>.png` |
| `Фото/` | фото шлемов, имя файла = артикул |
| `Генерация/` | эталоны сцен для кадров 1, 2, 4; промпты и проверки генераций (`Генерация фото.md`) |
| `Исходные данные/` | выгрузка поставщика как есть, не правится |
| `Материалы задания/` | задание, дизайн-система, требования к фото |

## Как устроен файл Figma

На тарифе Starter доступно 3 страницы.

- **Компоненты.** Переменные (Цвета, Отступы, Радиусы), 14 текстовых стилей, атомы (Метка типа,
  Шапка, Строка характеристики, Плитка акцента, Панель, Фото) и 4 компонента-карточки
  `Карточка/1 Обложка … 4 Защита`. У каждой карточки 5 вариантов «Тип». В секции «Исходник» лежит
  ручной макет, с которого собрана система.
- **Мастер-макет.** 4 кадра AVT-MD-M — эталон для копирования.
- **Выдача.** Готовые карточки артикулов.

## Как собрать новый артикул

1. Скопируйте 4 кадра со страницы «Мастер-макет» на «Выдачу» и переименуйте их в `<Артикул>_1…4`.
2. На каждом кадре выберите вариант **Тип** = поле «Тип шлема». Метка поменяет цвет и текст сама.
3. Заполните свойства по таблице ниже. Внутрь слоёв не заходите.
4. Значение `?????` вписывайте как есть: строка остаётся на кадре, кадр уходит заказчику как черновик
   (`_draft` в имени PNG). Для `—` выключите соответствующий «Показать…».
5. В свойстве **Фото** выберите фото артикула.
6. Проверьте кадры по `Критерии кадра.md` и экспортируйте PNG 1× в `Экспорт/`.

| Кадр | Свойство | Столбец `Данные.csv` |
|---|---|---|
| 1 | Модель / Линейка (Показать линейку) / Размер | Модель / Линейка / Размер |
| 1 | Выгода / Выгода, пояснение | Главная выгода: до двоеточия / после него. Двоеточия нет → пояснение выключить |
| 2 | Материал скорлупы, Замок ремня, Подкладка, Вес, Вентиляция | одноимённые столбцы |
| 3 | Обхват головы | Обхват головы, см |
| 4 | Подпись визора / Визор | Подпись визора / Визор |
| 4 | Сертификат, Гарантия, Страна производства | одноимённые столбцы |

## Решения по данным

- Форматы приведены к единым: обхват `59–60`, тип с заглавной, вес `1450 г`, гарантия `2 года`.
  Подробности — в журнале правок.
- Нет данных → `?????`. Строка остаётся на кадре с `?????`, чтобы отправить макет заказчику вовремя
  и он увидел, что нужно дозаполнить. Сейчас это только вес AVT-OF-L (кадр 2) — на контроле.
- У кроссового визора нет → `Нет`: выводится как значение.
- Название разбито: «Полное название» (как у поставщика), «Модель» (крупно на обложке, ≤ 8 символов),
  «Линейка» (мелко над моделью; если её нет — `—`, слой выключается).
- Подпись строки визора — «Визор солнцезащитный», если он есть, иначе «Визор».

## Открытые вопросы

- Вес AVT-OF-L — ждём ответа заказчика.
- Белый текст на метке «Кроссовый» даёт контраст 4,47 : 1, это чуть ниже 4,5. Цвет взят из
  дизайн-системы; принято как исключение.
