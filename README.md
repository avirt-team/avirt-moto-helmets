# Мотошлемы АВИРТ — мастер-макет карточек

Магазин АВИРТ выходит на маркетплейс с десятью шлемами, по четыре кадра на артикул (обложка, характеристики, подбор размера, визор и защита). Вместо сорока кадров здесь один мастер-макет в Figma: новый артикул собирается подстановкой данных через свойства компонента, без захода внутрь слоёв. Кадр 1080 × 1440, всё на автолаяутах.

**Figma:** ссылка на файл — https://www.figma.com/design/MV8gIElP1NX95Lr42bVIId (доступ на просмотр).

## Как открыть макет

В файле Figma три страницы:
- **Мастер-макет** — четыре набора компонентов: «Кадр/Обложка», «Кадр/Характеристики», «Кадр/Подбор размера», «Кадр/Визор и защита». В каждом пять вариантов по типу шлема: Интеграл, Модуляр, Кроссовый, Открытый, Адвенчер.
- **Компоненты** — основа (цвета, отступы, радиусы, стили текста), фото, атомы и блоки.
- **Проверка** — тестовые экземпляры: длинные значения и выключенные поля.

## Как собрать новый артикул

1. Взять строку артикула из `Данные.csv`. На странице «Проверка» поставить по одному экземпляру каждого из четырёх наборов.
2. В панели справа в списке «Тип» выбрать тип шлема из колонки «Тип шлема».
3. Заполнить текстовые свойства значениями из строки (название модели, материал, вес, замок ремня и так далее).
4. Если значения нет, выключить переключатель «Показывать: …» этого поля. Блок исчезнет, соседние сами сдвинутся. Если пустое поле обязательное (вес AVT-OF-L), вписать «?».
5. Фото: взять слой `Фото/<артикул> 1` со страницы «Компоненты», раздел «02 Фото», и перенести заливку на «Слот фото» кадра (скопировать слой, выделить слот, Ctrl+Alt+V).
6. Экспорт: выделить кадр, в разделе Export справа выбрать PNG 1×.

Цвета и шрифты не меняются вручную: цвета в переменных («Цвета», «Роли»), шрифты в текстовых стилях. Акцентный цвет меняется одной правкой переменной «Сигнал».

## Как решены неровности в данных

- Обхват головы: везде длинное тире без пробелов (`59–60`).
- Тип шлема: `Интеграл` с заглавной буквы у AVT-FF-XL.
- Гарантия: у AVT-MD-L `24 месяца` заменено на `2 года`.
- Визор: у кроссовых шлемов вместо пустой ячейки `Нет`.
- Вентиляция разбита на колонки «входов» и «выходов» (числа).
- Добавлена колонка «Козырёк» (`Есть` у Кросса и Адвенчера).
- Вес AVT-OF-L отсутствует в данных и в интернете. Ячейка пустая, помечена в колонке «Примечание», на кадре стоит красный «?».
- По каждой строке, что именно менялось, написано в колонке «Примечание» файла `Данные.csv`. Исходные значения видны в истории git.
- Самое длинное название — «АВИРТ Турер Модуляр Плюс Комфорт Эдишн» (38 символов). Оставлено как есть, правило: не более 40 символов, перенос до 3 строк (см. [Критерии кадра.md](Критерии кадра.md)).
- Оставлено как есть: Pinlock внутри поля «Визор», разный набор размеров у моделей.

## Ограничения

- Фото подставляется заливкой слота, а не свойством компонента.
- Тёмная тема не делалась: в переменных пока один режим.
